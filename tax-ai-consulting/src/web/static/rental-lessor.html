자동말소로 「기한 없이」 유지되던 중과배제가 조정지역 아파트에 한해 시한부가 되는 것이 핵심 변화. B가 비조정지역이거나 아파트가 아니면 직접 대상이 아님(확정 조문 확인 필요).

장특공 체계 개편: 2028.1.1 이후 양도분부터 「장기거주소득공제」(거주 연 8%, 최대 80%)로 전환, 공제한도 2028년 20억 → 2029년 10억. 등록임대 임대기간은 연 2%·최대 30%까지 거주기간으로 인정하되 조정대상지역 아파트는 인정 제외 → B아파트는 실거주하지 않는 한 2028년 이후 장특공 사실상 소멸. A거주주택은 실거주 기간이 길수록 개편 후에도 불리하지 않음.

종부세 개편: 2027년(과세기준일 2027.6.1)부터 세율이 주택수 → 가액 기준 전환. 다주택 기본공제 = 「4억 + 5억 × (거주주택 공시가 / 보유주택 공시가 합계)」, 공정시장가액비율 70%(2027) → 80%(2028), 세부담상한 200%. B 계속 보유 시 보유세가 매년 누적 증가. B 처분으로 1주택이 되면 A는 실거주 기준 기본공제 14억(비거주 9억).

다주택 중과 한시완화(별도 트랙): 조정대상지역 2년 이상 보유주택은 2027년 +5%p(2주택)/+10%p(3주택 이상), 2028년 +10%p/+15%p로 완화 후 2029년 원복. 중과배제를 못 받는 상황에서 출구로 활용 가능.

(2) 설계 예시 — 시가 10억 아파트, 자동말소 후 2027년 내 양도 가정

  • 매매가액 7억 — 할인 3억 = Min(10억×30%=3억, 3억) → 증여세 0
  • 부모 양도세 — 시가 10억 기준 양도차익 계산. 조정지역 아파트라도 2027년 내 양도 시 중과배제 + §97의3 장특공 50% 적용 → 세부담 대폭 축소. 같은 거래를 2029년에 하면 시가 10억 기준 + 중과세율 + 장특공 0으로 세액 급증
  • 자녀 취득세 — 시가인정액(감정가·매매사례가액 등) 기준. 중과 취득세 여부는 자녀의 세대·주택수 기준으로 별도 판정
  • 자녀의 향후 취득가액 — 실제 지급 대가 7억(+증여의제 과세분 가산). 자녀가 나중에 팔 때 양도차익이 커지는 트레이드오프 → 자녀가 장기 실거주(1세대1주택 비과세 목표)할 계획일 때 효율이 가장 높음
