국세청·행정안전부가 공동 작성한 주택 세금 해설서(2026년판, 국세청 누리집 2026.8.24. 게시)를 검색 가능한 텍스트로 정리한 폴더입니다.
취득·보유(재산세·종부세)·임대·양도·증여·상속까지 393쪽(이북 이미지 기준).

- 원문 이북: 국세청 > 국세정책/제도 > 통합자료실 > 국세청 발간책자 > 세금안내 책자 > "2026년 주택과 세금"
- 국세청은 이북(웹 뷰어)만 제공하고 PDF는 제공하지 않음

## 폴더 구성

| 파일 | 내용 |
|---|---|
| `toc.md` | 목차 + 책 쪽수 색인 — **먼저 여기서 위치 확인** |
| `조정대상지역.md` | 조정대상지역 지정·해제 연혁표 + 세목별 영향 정리 (**이미지를 직접 보고 옮긴 검증본**) |
| `fulltext.md` | 전체 OCR 텍스트 한 파일 (`## img NNN (책 N쪽)` 구분) |
| `pages/pNNN.txt` | 이미지 1장 = 파일 1개 OCR 텍스트 |

**쪽수 규칙: 책 쪽수 + 2 = 이미지 번호.** 예) 책 230쪽 → `pages/p232.txt`

## 페이지 이미지 (원본 대조용)

이미지(1600px JPEG, 393장, 약 85MB)는 main을 가볍게 유지하려고 **별도 브랜치**에 둡니다.

```bash
# 브랜치: data/ebook-nts-housing-tax-2026  (루트에 p001.jpg ~ p393.jpg)
git fetch --depth 1 origin data/ebook-nts-housing-tax-2026
git show FETCH_HEAD:p232.jpg > p232.jpg          # 한 장만 꺼내기
```

웹에서 보기: `https://github.com/daehantax/property/blob/data/ebook-nts-housing-tax-2026/p232.jpg`

## 주의

- `pages/`·`fulltext.md`는 **자동 OCR(Tesseract)** 결과라 표·굵은 제목·숫자에 오인식이 있습니다. **세율·날짜·금액은 반드시 해당 페이지 이미지로 확인**하세요.
- 책자 기준일 이후 개정 사항은 반영돼 있지 않습니다(책자도 "실제 적용 시 법령·예규 확인" 안내).
- 책자 분담: 국세청(종부세, 임대·양도 소득세, 상속·증여세) / 행정안전부(취득세, 재산세)
